## Deskripsi Singkat
Dashboard ini dibuat untuk menganalisis pola penyewaan sepeda berdasarkan faktor waktu seperti musim, hari, serta kondisi lingkungan. Analisis dilakukan menggunakan dataset Bike Sharing periode 2011–2012.


## Insight Utama
- Musim memiliki pengaruh signifikan terhadap jumlah penyewaan sepeda.
- Terdapat perbedaan pola penggunaan antara hari kerja dan akhir pekan.
- Hari tertentu dalam seminggu menunjukkan tingkat penyewaan tertinggi.
- Faktor lingkungan seperti suhu berkontribusi terhadap peningkatan penggunaan sepeda.
